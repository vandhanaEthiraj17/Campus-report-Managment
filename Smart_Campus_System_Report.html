1. Executive Summary & Core Workflow

The Smart Campus Issue Reporting & Maintenance Management Platform is an enterprise-grade full-stack solution designed to streamline facility maintenance, infrastructure repairs, and asset management across university campuses.

End-to-End System Workflow

1
Domain-Validated Identity Registration
User enters official college email (e.g. @adhiyamaan.ac.in). Public self-registration is strictly scoped to the STUDENT role.
2
SHA-256 Hashed OTP Verification
Backend issues a 6-digit OTP (5-min expiry, 60s cooldown, max 3 attempts). Account creation is finalized only after OTP verification.
3
Issue Reporting & Real-Time Duplicate Prevention
Students/Faculty file complaints with location, category, priority, and images. The system checks existing active tickets to prevent duplicate reporting.
4
Admin Command Center & Technician Dispatch
Admin evaluates queue metrics, filters master tickets, assigns specialized technicians (Electrical, Plumbing, IT, Civil), and provisions Faculty/Staff accounts.
5
Repair Proof Upload & Resolution Feedback
Technicians accept assigned tasks, update status to In Progress, and upload repair proof photos (afterImages). Reporter verifies resolution and provides feedback ratings.
6
Automated SLA Escalation Cron Service
Background service monitors SLA target dates every 10 minutes. Overdue complaints automatically trigger SLA breach escalation flags (isEscalated: true).

2. System Security & RBAC Matrix

The system enforces strict Role-Based Access Control (RBAC). Every protected route queries MongoDB directly in authMiddleware.ts, ignoring any client-side role claims.

Role Creation Method Permitted Actions & Capabilities
Student Public OTP Registration File issue tickets, view own reported complaints, upvote community issues, track ticket status, verify completed repairs, submit feedback.
Faculty Admin Provisioned Raise department tickets, view campus complaints, track status, verify completed maintenance.
Technician Staff Admin Provisioned View department queue, accept assigned tasks, update status (In Progress / Resolved), upload repair proof photos.
Admin Seeded / Super Admin Master dispatch queue, technician assignment, user management (activate/deactivate), privileged provisioning, audit logs, CSV export.

4. Future Roadmap & Strategic Enhancements

Recommended Next Phase Features

  • Live SMTP Email & SMS Gateway: Integrate Nodemailer (SendGrid / AWS SES) for live OTP dispatch and Twilio for SMS alerts.
  • Real-Time WebSockets (Socket.io): Instant browser push notifications for technician task assignments and live ticket status updates.

  • Spatial Heatmap Analytics: Interactive 2D campus map visually highlighting high-maintenance building zones in real-time.
  • AI Vision Photo Categorization: Machine learning model to analyze uploaded damage photos and auto-suggest fault category and priority.
